# 🍽️ Vite & Gourmand - Front-end

## Description
Application web de commande de menus événementiels .

## Prérequis
- Node.js / npm (pour la gestion des dépendances UI si applicable)
- Un navigateur web récent

## Installation en local
1. Cloner le dépôt :

bash
git clone <url-du-depot-github>

## Installer les dependances 

bash 
npm install

## lancer l'application

bash
npm run dev
